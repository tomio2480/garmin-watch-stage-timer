# Store Description (English)

## Short Description (max 100 characters)

Countdown timer for presentations with visual color changes and vibration alerts.

## Full Description

Stage Timer is a countdown timer designed for speakers and presenters. Track your remaining time with visual feedback (color changes) and haptic alerts (vibrations).

### Features

- Countdown timer from 1 to 60 minutes
- Two customizable alert points with color changes (yellow, magenta)
- Final 5-second countdown with per-second vibration
- Time's up screen with continuous vibration
- 4 built-in presets (5min, 15min, 20min, 45min)
- Configure via Garmin Connect Mobile app

### How to Use

1. Select a preset or customize duration and alert times
2. Press the action button or tap to start
3. Tap to pause/resume
4. Long press to reset

### Privacy

This app does not collect any personal data. No internet connection, sensors, or permissions required.
